# 可选工具接入说明

Bookflow 的核心是可复核的制作顺序、每期文件和本地检查命令。第三方工具不是仓库依赖；不同使用者可以替换成自己已有的服务。安装某个工具不代表已取得书籍内容、声音或素材的使用权。

| 环节 | 可选工具/来源 | 用途 | 使用边界 |
| --- | --- | --- | --- |
| 资料与读者兴趣 | 出版社/作者公开资料；用户本人已授权的读书笔记服务（如微信读书） | 核对书目事实；从用户自己的划线中发现可能值得讲的主题 | 公开事实应保留可追溯来源；划线只作选题线索，口播需原创，不复制长段原文 |
| 图片/视频素材 | 用户拍摄、已获授权素材或当前环境可用的图片/视频生成工具 | 按已确认分镜准备画面 | 素材需记录来源和使用权；不要把未授权书封、截图或音乐放进公开仓库 |
| 旁白与时间码 | 用户录音、获批的 TTS；可选 Whisper/其他 ASR | 生成旁白，并为字幕提供初始时间参考 | ASR 时间码必须听音复核；不得擅自克隆或合成未经同意的真人声音 |
| 剪辑与合成 | HyperFrames、CapCut 或其他剪辑器/渲染器 | 按分镜、字幕和音频输出视频 | 工具需由使用者另行安装配置；渲染结果必须实际预览，CLI 不会代替画面质检 |

## 最小接入顺序

1. 先按 README 安装并使用 `skills/bookflow/`，建立一期目录。
2. 在本地选定资料、生成媒体、旁白和剪辑工具；服务密钥只放本地环境，不写进仓库或 episode 公共示例。
3. 按已批准口播填写分镜和字幕。ASR 可以提供时间参考，但中文字幕仍以获批口播为准。
4. 使用剪辑器预览并导出，再运行：

   ```powershell
   npm test
   npm run bookflow -- check <episode-folder> --release
   ```

当前 CLI 负责文件结构、文本对应、字幕时间和发布文件存在性检查。它不会联网验证资料真实性，不会调用读书、图像或语音 API，也不会渲染视频。
